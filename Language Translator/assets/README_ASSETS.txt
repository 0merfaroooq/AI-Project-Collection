Place optional branding images here:
  - logo.png    (recommended size: 128x128 or 256x256, transparent PNG)
  - banner.png  (recommended size: 1600x400, used as an optional hero banner)

These are not required for the app to run. The app's hero section is
built entirely with CSS/HTML, so it looks polished even without custom
images. If you add banner.png, you can display it in app.py with:

    st.image("assets/banner.png", use_container_width=True)
